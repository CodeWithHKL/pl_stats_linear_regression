# Premier League goal prediction

Predicts how many goals a team scores in a Premier League match, using Poisson regression (scikit-learn)
trained on five seasons of match results.

## What it does

Given a fixture, it returns the **expected number of goals** for one team (a decimal like `2.83`, not a
whole-number scoreline). Two models are provided:

| Model | Inputs | Use it for |
|---|---|---|
| `fixture` | team, opponent, home/away | **Forecasting before kickoff.** Learns an attack and defence strength for each team. |
| `stats` | shots, shots on target, corners, home/away | **Explaining a match after it was played.** Shots are unknown before kickoff, so this can't forecast. |

Both are Poisson regressions because goals are counts that can't go negative.

## Setup

Requires Python 3.10+.

```
python -m venv .venv
# Windows:      .venv\Scripts\activate
# macOS/Linux:  source .venv/bin/activate
pip install -r requirements.txt
python -m src.fetch_data
```

`fetch_data` downloads the 2021/22–2025/26 seasons from [football-data.co.uk](https://www.football-data.co.uk/englandm.php)
into `data/pl_matches.csv`: 3,800 rows, one per team per match, with team, opponent, home/away, shots,
shots on target, corners and goals. The data is free for personal use; check the site's terms before redistributing it.

## Usage

```
python -m src.predict fixture --team "Man City" --opponent Burnley --home
# Expected goals: 2.83

python -m src.predict fixture --team Burnley --opponent "Man City"
# Expected goals: 0.68

python -m src.predict stats --shots 15 --on-target 6 --corners 5 --home
# Expected goals: 1.80

python goal_predictor.py      # cross-validated evaluation of both models
```

Team names must match the data (e.g. `Man City`, `Man United`, `Tottenham`, `Nott'm Forest`). An unknown name
prints the full list. Omit `--home` for an away team.

## Results

5-fold cross-validated mean squared error on goals per team per match (lower is better):

| Model | MSE | Predict-the-mean baseline |
|---|---|---|
| `fixture` | 1.42 | 1.62 |
| `stats` | 1.11 | 1.62 |

`stats` scores better because shots on target are close to goals themselves. `fixture` beats the baseline by
only about 12%, which is normal: football scoring is very noisy.

## Limitations

- Premier League teams only. Teams absent from the data (European clubs, newly promoted sides) can't be used.
- `fixture` ignores recent form, injuries, lineups and match importance.
- Cross-validation folds are unshuffled and ordered by season, so each fold is tested on a different period
  than most of its training data. Promoted teams the model has not seen are scored as average.
- It predicts expected goals, not win/draw/loss probabilities or exact scorelines.

## Project layout

```
data/pl_matches.csv generated by fetch_data
```
